# Auto-blog + SEO/GEO dashboard — how it works and how to switch it on

## What runs, when

| Workflow | Schedule (IST) | What it does |
|---|---|---|
| `.github/workflows/blog.yml` | every 2 days, 06:30 | picks a topic → researches with Claude + web search → writes in house style → **validates** → commits `content/blog/<slug>.md` + OG image → deploys → pings IndexNow |
| `.github/workflows/dash.yml` | daily, 05:00 | pulls Search Console, Cloudflare, Bing, GEO mention checks, sitemap coverage → `public/dash/data.json` → deploys |
| `.github/workflows/deploy.yml` | on push / dispatch | builds and publishes the site |

Both bots can also be run by hand: GitHub → Actions → pick the workflow → **Run workflow**. The blog one accepts a forced lane (`news`/`guide`) and a forced topic.

## Secrets to add (GitHub → Settings → Secrets and variables → Actions → New repository secret)

| Secret | Needed for | How to get it |
|---|---|---|
| `ANTHROPIC_API_KEY` | blog generation, GEO checks | console.anthropic.com → API keys. Sonnet: roughly $0.15–0.40 per post incl. research. |
| `GSC_SERVICE_ACCOUNT` | Google Search Console data | Google Cloud Console → new project → IAM → Service Accounts → create → Keys → JSON. Enable "Google Search Console API" on the project. Then in Search Console → Settings → Users and permissions → add the service-account email as **Full** user. Paste the whole JSON as the secret. |
| `GSC_SITE` | | `sc-domain:jothiswaroop.com` (domain property) or `https://jothiswaroop.com/` (URL-prefix property) — whichever the Search Console property is. |
| `CF_API_TOKEN` | Cloudflare Web Analytics | dash.cloudflare.com → My Profile → API Tokens → Create → custom → **Account Analytics: Read**. |
| `CF_ACCOUNT_TAG` | | Cloudflare dashboard URL: `dash.cloudflare.com/<ACCOUNT_TAG>/…` (32 hex chars). |
| `CF_SITE_TAG` | | Web Analytics → the site → "Site tag" (it is the same value as the beacon `token`: `190178a9bb5a4ba6bdaea040a85daafa`). |
| `BING_API_KEY` | Bing queries (optional) | bing.com/webmasters → add site → Settings → API access → generate. Also submit the sitemap there once. |

Nothing else. No keys live in the repo or the browser.

## Quality gates a post must pass (scripts/blog/validate.mjs)

- 2–6 sources, at least one on an official/primary domain; every source URL linked in the body; every external link declared as a source; every link returns < 400
- **every number in the post appears in the fetched source text** (or in the fixed RECEIPTS list) — no invented figures
- key-facts box, 3–7 H2s, a "What I'd do Monday" section, 3–5 FAQs, 1–3 internal links from the allowed list
- banned AI-tell phrases (list in `STYLE.md`), no bold in headings, no summary ending, word count per lane
- title ≤ 80 chars, description 120–170 chars, slug 3–7 words, tags/segment from the allowed lists

If a draft fails twice it is **not published**; it's uploaded as a workflow artifact (`rejected-draft`) for a human to look at.

## Where things live

- Posts: `content/blog/*.md` (front-matter contract in `lib/blog.ts`). Hand-written posts go here too — run `npm run blog:validate content/blog/<file>.md` first.
- Style guide the writer follows: `scripts/blog/STYLE.md`. Edit it to change the voice.
- Topic queue for guide posts: `scripts/blog/topics.json`. Add rows; the bot works down the list.
- News feeds + keyword filter + official domains + internal links + receipts: `scripts/blog/config.json`.
- What's been covered: `scripts/blog/covered.json` (bot-maintained).
- GEO prompts tracked daily: `scripts/dash/geo-prompts.json`.
- Dashboard: `/dash/` (noindex, not in nav or sitemap). Data: `public/dash/data.json`.
- OG images: `public/blog/og/<slug>.png`, generated by `scripts/blog/og.mjs` (also runs in `prebuild`).
- RSS: `/feed.xml`. IndexNow key file: `public/<key>.txt`.

## Changing the cadence

`blog.yml` → `cron: "0 1 */2 * *"` is every 2 days at 01:00 UTC (06:30 IST). Weekly would be `"0 1 * * 2"` (Tuesdays).

## Honesty rules baked in

- The writer may only use Jothi's own numbers from the RECEIPTS list in `config.json`, verbatim. Everything else must be sourced and linked.
- Posts are published under Jothi's name. The research and drafting are automated; the voice, rules and receipts are his. If a reader asks, the honest answer is "researched and drafted with AI, published under my rules, every number sourced".
